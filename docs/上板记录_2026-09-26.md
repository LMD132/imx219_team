#### 3.4.1 串口通道上板实测 —— 9/9 OK

主机端口 **COM5** = FT4232H channel C（COM6 = channel D，不接 FPGA）。
115200 8N1。测试脚本 `tools/link_test.py COM5`：

```
idle       M2 T0024 LO0021 HI0058 MED1 GAU0 ISO1 DSP0 OVC1   (每 500ms 一行)
T200    -> T0200 OK        T=16 -> T0016 OK       m0   -> M0    OK
D1      -> DSP1  OK        T9999 -> T2047 OK      H3000 -> HI2047 OK
n0      -> MED0  OK        "T7 L8 H9" -> T0007 LO0008 HI0009 OK
R       -> 恢复默认 OK
RESULT 9/9
```

命令分隔符宽松（`=`、空格、小写均可）、数值**饱和**（`T9999` 得 2047 不回绕）、
一行可多条命令 —— 三件事都在真板上得到验证，不只是仿真。

#### 3.4.2 界面真板端到端测试 —— PASS

1. `alg_cfg_uart.v` 饱和累加器位宽不足（`reg [12:0]` 装不下 `2047*10+9=20479`），

## 4. 复现命令

```bat
cd /d D:\FPGA_Project\imx219_pyrtl
tools\flash_candidate.bat candidate_bitstreams\algo_uart_tuner_splitonly_20260926_2037.bit
```

### 4.1 本机特有的两个环境坑（已封装进脚本）

1. **`EFINITY_HOME` 被设成了用户级环境变量**（值 `C:/Efinity/2026.1`）。
   而 `C:\Efinity\2026.1\pgm\bin\ftdi_pgm.bat` 开头是：

   ```bat
   if not defined EFINITY_HOME ( call "%~dp0\..\..\bin\setup.bat" )
   ```

   于是它**跳过** `setup.bat` → `PYTHONHOME` 没被设置 → 内置 Python 直接崩：

   ```
   Fatal Python error: init_fs_encoding: failed to get the Python codec of the filesystem encoding
   ModuleNotFoundError: No module named 'encodings'
   ```

   解决：**先显式 `call setup.bat`**，再调 `ftdi_pgm.bat`。

2. **`EFINITY_USER_DIR` 需要手动设**。`setup.bat` 只设了 `EFINITY_USER_DIR_INI`
   （指向 `%LOCALAPPDATA%\efinity\user_dir.ini`），而板卡 profile 加载器
   （`efx_pgm/efx_hw_common/boards.py`）直接读 `EFINITY_USER_DIR`，
   否则报 `KeyError: 'EFINITY_USER_DIR'`。
   本机该值 = `C:\Users\HUAWEI\.efinity`（从 `user_dir.ini` 里读到）。

### 4.2 脚本文件必须是纯 ASCII

cmd.exe 按 OEM 代码页（本机 GBK）解析 `.bat`，中文注释会变成
`'xx:' is not recognized as an internal or external command`。
脚本里的注释因此全用英文。
