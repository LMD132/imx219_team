# FPGA-Python —— 赛题4 图像处理离线调参工作台

用电脑(摄像头/图片/视频)先把"边缘检测 + 去噪 + 阈值"的算法选型和参数区间调好，
再把最优参数交接给板上队友，减少烧板试错。**纯软件运行，不需要芯片。**

## 文件说明

| 文件 | 作用 |
|---|---|
| `edge_pipeline.py` | 核心流水线：灰度化 → (噪声模拟) → 中值/高斯滤波 → Sobel/Canny(含NMS) → 阈值 → 分屏 → 彩色叠加 → 形状识别。整数运算，贴近 Verilog。 |
| `live_tune.py` | 摄像头/图片/视频实时调参：滑条实时改阈值/滤波/噪声/算法/彩色/识别，按键切换模式。 |
| `batch_sweep.py` | 离线批量预筛：对图片扫描「滤波 × 阈值」网格，输出对比图 + 指标报告 + 推荐参数。 |
| `features_demo.py` | 高阶功能离线演示：一张图上同时验证 Canny / 彩色叠加 / 圆形矩形识别，输出五栏对比图。 |
| `requirements.txt` | 依赖清单。 |

## 实时调参使用说明（live_tune.py）

> **OpenCV 窗口在 Windows 上不支持中文控件名**（否则会出现乱码），所以滑条与窗口标题用英文缩写：
> `MODE`=模式(0=单阈值 1=双阈值)、`ALGO`=算法(0=Sobel 1=Canny含NMS)、`THR`=阈值、
> `THR_HI`=高阈值、`THR_LO`=低阈值、`MEDIAN`=中值滤波、`EPF`=边缘保持滤波(0=关 1=高斯3x3 2=导向滤波)、
> `NOISE(0.001x)`=椒盐噪声（实际值=滑条值×0.001）、`COLOR`=彩色叠加(0=黑白 1=红边 2=方向色)、
> `SHAPE`=形状识别(0=关 1=开)、`TRACK`=红框模式(0=固定中心 1=跟随目标)、`BOX(%)`=红框大小。

- **滑条**：MODE(单/双阈值)、ALGO(Sobel/Canny)、THR、THR_HI/THR_LO、MEDIAN、EPF(0/1/2)、NOISE(模拟传感器抖动)、COLOR(彩色叠加)、SHAPE(形状识别)、TRACK(红框固定/跟随)、BOX(%)。
- **EPF=2 导向滤波注意**：实测会明显丢失细节（眼镜、键帽等小结构），且不解决帧间闪烁（它是空间滤波，不是时间滤波）——已按 SIGGRAPH2011 域变换论文结论定性为"必然丢细节"，**不建议用于边缘检测前置**，仅保留作 A/B 对比实验。
- **按键**：`q`退出 `s`保存截图到 samples/ `t`切换单/双阈值 `m`切换分屏/仅边缘/仅灰度 `n`开关红框。
- **闪变px**：当前帧与上一帧边缘的异或像素数，开 NOISE 后可直接观察哪组参数白点更稳。
- **形状识别提示**：文字笔画容易形成小闭合圈被误判为小圆，可通过提高 `detect_shapes()` 的 `min_area` 过滤。

## 批量预筛说明（batch_sweep.py）

- 对每张图输出 `out/sweep_<名>.png`（网格对比）和 `out/report_<名>.md`（密度+闪变指标、推荐参数）。
- 指标：**密度%**（边缘像素占比，越高=细节保留越多）；**闪变px**（两帧不同噪声下边缘异或像素，越小越不易闪）。
- 推荐逻辑：每个滤波方式取"密度≥最优60% 且 闪变最小"的阈值，再跨方式取综合最优。

## 与 Verilog/RTL 的差异（交接给队友时注意）

1. **算法选型、大方向结论完全通用**：中值比高斯保细节、双阈值能同时压噪声和保弱边缘，这些板上同样成立。
2. **数值有 ±1~2 截断偏差**：Python 整数右移与 RTL 移位实现略有差异，同一阈值板上可能差 1~2。
3. **闪烁是时域现象**：静态图看不到"帧间闪"，本工具用"椒盐噪声 + 帧间异或"近似模拟；最终必须上板确认实时效果。
4. 摄像头传感器不同（USB 摄像头 vs IMX219），最优阈值区间可能整体平移，但区间宽度不变。

## 给队友的参数交接模板

在 report 里找到"综合最优"，按如下格式发给队友：

```
算法: 3×3 中值滤波(开) + 高斯(关)
阈值: 单阈值 T=24~28 区间内试 2~3 个值(我这边 26 最优)
双阈值: 高 36~44 / 低 12~20 (我这边 40/16)
注意事项: 上板重点看白墙等平坦区域是否闪白点; 若闪则优先固定 IMX219 增益/曝光, 而不是继续抬阈值
```

## 2026-09-26 增强(参考 GitHub 成熟工程)

新增三档可调项(live_tune 滑条 TEMP / ISOL, 按键 o), 直接对应"白点闪烁 vs 细节丢失":

1. TEMP 时间域帧间平均 (0~90): 越大压闪烁越强, 建议 20~40 (alpha=0.7~0.8 保留当前帧)。原理同 EricYXZ/ti60f225-image-processing-fpga 的帧平均模块 (GRAY5x5_WEIGHTED_INTERNAL_FRAMEAVG)。
2. ISOL 孤立点消除 (0/1): 只删除"周围一个白邻居都没有"的孤立单像素白点(闪烁白点), 1px 边缘线(含端点)完整保留, 原理同"红外技术"论文的腐蚀去孤立点。
3. 按键 o: Otsu 自动阈值——按当前画面自动设 THR(单阈值模式), 光照变化时一键重定; 结果<=0 自动回落 40。
   参数佐证: 灰度 (77,150,29)>>8 与 EricYXZ 同平台 RTL 逐位一致; 5x5 高斯核 [32,38,40,38,32;...;32] 总和 1010 右移10(约 /1024); 中文例程 8-bit 阈值常用 40~80, 建议单阈值 24~45 保留细节、双阈值低≈0.4~0.5x高。

推荐组合: MEDIAN=1 + GAUSS=0 + 双阈值 45/24 + TEMP=30 + ISOL=1, 若还闪再单独抬 THR_HI。
